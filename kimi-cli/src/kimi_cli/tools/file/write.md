Create or fully replace a UTF-8 text file.

Defaults to overwrite, replacing the whole file — use caution. For content over 100 lines, split into multiple calls; use append after the first write. For targeted changes, use edit instead of rewriting the whole file.

Conflict resolution: file_path accepts conflict://<N> to resolve a single registered conflict block, or conflict://* to bulk-resolve every registered block. The content may use the @ours / @theirs / @base / @both line tokens to splice recorded sections. Regular writes refuse by default when the resulting content still contains conflict markers; pass allow_conflicts=True to override.

Auto-generated guard: overwriting (or appending to) an existing file that appears machine-generated — filename patterns like zz_generated.*, *.pb.go, *_pb2.py, *.gen.ts, *.swagger.json, or a header marker such as @generated / Code generated by … — is refused by default so codegen cannot silently overwrite your change. Edit the source (schema, template, generator input) and regenerate instead, or pass allow_auto_generated=True to override.

Safety: successful writes record pre/post-write snapshots in the session snapshot store (bounded, in-memory) and bust stale filesystem caches, so a mistaken overwrite stays recoverable within the session.
